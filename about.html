Mission

ミッション

自由な発想が、
次の当たり前をつくる。 THINK UPSIDE DOWN.

いま「当たり前」とされているものは、かつて誰かの自由な発想から生まれました。私たちFreedomは、常識や前提をいったん疑い、逆さから眺め直すことから仕事を始めます。ITソリューション、広告、アパレル、ECという領域の異なる4つの事業を通じて、業界の枠にとらわれない視点を掛け合わせ、お客様と社会に新しい価値を届けます。そうして生まれた価値が、いつか誰かの「次の当たり前」になる。それが私たちの目指す未来です。

VALUE

Our Values

私たちが大切にする3つの姿勢

ミッションを実現するために、Freedomの全員が日々の仕事で立ち返る行動指針です。

VALUE 01

逆さから見る

Think Upside Down

「そういうものだから」を疑うことから始めます。前提をひっくり返して眺めたときに見えてくる違和感こそが、新しい価値の入り口だと考えます。

VALUE 02

越境する

Cross the Border

IT・広告・アパレル・EC。事業も職種も飛び越えて知見を持ち寄るのがFreedomの流儀です。専門性の交差点にしか生まれないアイデアを大切にします。

VALUE 03

最後までやり切る

See It Through

発想の自由には、成果への責任が伴います。企画で終わらせず、開発・運用・改善まで伴走し、数字と品質で応えるまでが私たちの仕事です。

Logo Story

逆さの星に込めたもの

当たり前を、逆さから見る。OUR LOGO CONCEPT

Freedomのロゴは、逆さまに描かれたひとつの星です。星は、誰もが夜空に「見上げる」ものの象徴。目標、憧れ、正解——世の中で当たり前とされている見方そのものです。

私たちはその星を、あえて逆さにしました。上下をひっくり返した瞬間、見慣れたかたちは違和感に変わり、そこに問いが生まれます。「本当にそうだろうか」「別のやり方があるのではないか」。その問いこそが、自由な発想の出発点です。

常識や前提を疑い、逆さから眺め直すことで、まだ誰も気づいていない価値を見つけ出す。この逆さの星は、Freedomという社名に込めた「発想の自由」を貫くという、私たちの意思表明です。

Message

代表メッセージ

代表取締役** **

常識を疑うことは、
誠実であることだと思う。

「当たり前を、逆さから見る」。この言葉を、私たちは創業のときから大切にしてきました。奇をてらうためではありません。業界の慣習や「昔からこうだから」という理由だけで残っている仕組みを、そのままお客様に手渡すことは、誠実ではないと考えているからです。常識を一度疑い、それでも正しいと確かめられたものだけを届ける。遠回りに見えて、それが信頼への最短距離だと信じています。

Freedomは、ITソリューション、広告、アパレル、ECという4つの事業を営んでいます。一見ばらばらに見えるかもしれませんが、私たちにとっては地続きです。テクノロジーで仕組みをつくり、広告で想いを届け、アパレルでかたちにし、ECでお客様と直接つながる。異なる現場で得た学びを互いに持ち寄れることが、単一事業の会社にはない私たちの強みであり、自由な発想を生む土壌になっています。

お客様に対して約束するのは、課題の表面をなぞる提案ではなく、前提から問い直すパートナーであることです。そして社員に対しては、肩書や部署に縛られず挑戦できる環境と、挑戦の結果に誠実に向き合う文化を守り続けることを約束します。自由とは放任ではなく、考え抜く責任とセットである——それが私たちの考える「Freedom」です。

次の当たり前は、いつも小さな違和感から始まります。私たちはこれからも、逆さの星のように世界を眺めながら、お客様と社会にとって本当に価値のあるものをつくり続けてまいります。今後とも変わらぬご支援をよろしくお願いいたします。

History

沿革

小さな違和感から始まった挑戦は、事業の垣根を越えながら、いまも続いています。

  1. 20**年

    創業

    「当たり前を、逆さから見る。」を合言葉に、東京都***区にて株式会社Freedomを設立。

  2. 20**年

    ITソリューション事業開始

    受託開発・保守運用を中心とするITソリューション事業を開始。企業の業務システムやWebサービスの開発支援を本格化。

  3. 20**年

    広告事業開始

    開発現場で培ったデータ活用の知見を活かし、広告事業へ参入。企画からクリエイティブ、運用改善までを一貫して提供。

  4. 20**年

    アパレルブランド立ち上げ

    「発想の自由をかたちに」をテーマに自社アパレルブランドを立ち上げ。企画・生産から販売までを自社で手がける体制を構築。

  5. 20**年

    EC事業本格化

    自社ブランドの販売基盤として育てたECノウハウを外部にも展開し、EC事業として本格化。サイト構築から運営代行まで支援領域を拡大。

  6. 現在

    4事業を軸に、次の当たり前へ

    IT・広告・アパレル・ECの4事業を掛け合わせ、業界の枠を越えた価値づくりに挑戦し続けています。
