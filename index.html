01 / Payment management

Wire Pay

決済の流れを、ひとつの管理画面に。

デモを見る ↗

決済申請から売上確定、返金、加盟店への精算まで。
複数の支払い方法にまたがる業務をまとめて管理するダッシュボードです。

  • 決済・返金・精算
  • 加盟店・権限管理
  • レポート・CSV出力
  • 日本語 / English

数字から、決済の動きを読み取る。

決済件数・成功率・金額の推移を確認。期間や加盟店で絞り込み、CSVで出力できます。

レポート画面を見る ↗

自主制作アプリのデモ画面です。掲載データはサンプルです。

02 / QR payment

Any Pay

見せる、読み取る。QRでつながる支払い。

デモを見る ↗

スマートフォンにQRを表示して支払う。お店のQRを読み取って支払う。
2つの支払い方に、チャージ・送金・割り勘をまとめた決済アプリです。

  • QRコード表示
  • QRスキャン
  • チャージ
  • 送金・割り勘

デモアカウントの画面です。掲載QRは画面例です。

03 / Multi-currency e-wallet

payCcount

通貨を持つ。両替する。そのまま支払う。

デモを見る ↗

法定通貨・暗号資産・ポイントを、ひとつのEウォレットで管理。
チャージから両替、国内外のEC決済までをつなぎ、加盟店は自国の通貨で受け取れます。

  • JPY / USD / EUR / GBP
  • BTC / ETH
  • ポイント
  • EC決済連携

模擬残高によるデモ画面です。実資金・暗号資産は扱いません。

04 / Payment infrastructure

ExPress

口座の残高で、買い物を完結する。

デモを見る ↗

利用者・店舗・運営をつなぐ決済基盤のプロトタイプ。
支払いから、その後の売上確定・返金までをひと続きに設計しています。

  • 残高払い
  • 売上確定・部分返金
  • 継続課金
  • API / SDK連携

支払いから、その先まで

残高払いに加え、売上確定・部分返金・継続課金の処理を実装。

ECサイトとつなぐ

サンプルECをAPI・SDKで接続し、Webhookで決済後の処理へ。

個人による自主制作プロジェクトです。

05 / Point of sale

個人店舗向けレジアプリ

注文からキッチン、お会計まで。

デモを見る ↗

個人店の日々の仕事に寄り添う、店舗レジアプリ。
テーブルごとの注文と提供状況を共有し、接客から会計までを支えます。

  • テーブル別注文
  • キッチン連携
  • 会計・釣り銭計算
  • 売上履歴

注文を、迷わず共有

商品やトッピングを選び、卓ごとの伝票と調理・提供状況を管理。

日々の店舗運営を支える

釣り銭計算、売上履歴、メニュー管理。ホールとキッチンで役割を分担。

個人による自主制作プロジェクトです。
